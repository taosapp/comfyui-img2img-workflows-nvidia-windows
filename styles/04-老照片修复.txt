# ===== 实测经验（2026-09-28，6.jpg 重度污损合影） =====
# 1. 保守措辞（"repair... keep exactly the same"）对重度污损几乎无效——模型会把
#    "保持原样"执行得比"修复"更狠，污损原样保留。重度破损要用 "restore to how it
#    originally looked / reconstruct / rendered clearly and cleanly" 这类强措辞。
# 2. 代价：脸部是"合理重建"而非真实还原（原照片里脸已经糊了，这是物理极限）。
#    多换几个种子（KSampler 设 fixed 后改 seed）挑最像的一张。
# 3. resolution：实际输出宽 = round(√(res²·宽高比)/32)·32。4:3 的横图 =>
#    res=1024 → 1152×864；res=1344 → 1536×1152；res=480 → 544×416（快约 4.6 倍）。
# 4. 轻度污损（只有折痕黄斑、脸还清楚）用保守变体即可，不会重画脸。
# 5. **看不见的信息要靠提示词写死，而且矫枉必须留余地**（三次迭代教训）：
#    - 人种：不写就把中国人修成非洲/土著面孔 → 写 "Chinese, East Asian eyes with epicanthic fold"，
#      负向词排除 african/caucasian/native american features。
#    - 年龄是**双向**的：不写会修成 40 岁；但正向堆 "no wrinkles / delicate refined beautiful /
#      classic beauty" 又会修成 15 岁偶像脸。正确做法 = 正向写 "about 20 years old, adult young
#      women, ordinary real women, natural unglamorous, little or no makeup"，
#      负向词两头排除：middle aged / wrinkles / grey hair + child / teenager / underage。
#    - **脸型轮廓是修复的底线**：必须显式写 "keep the original head shape, face outline, face shape,
#      jawline, cheekbones and facial proportions; do not slim, widen or reshape; do not make the two
#      faces look alike"，负向词加 slim face / v-shaped jaw / reshaped face / idealized beauty /
#      beauty filter / idol face。否则模型会把两个人改成同款"标准美"脸。
