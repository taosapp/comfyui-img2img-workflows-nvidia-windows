# ===== 实测经验（2026-09-28 ~ 09-29，6.jpg 重度污损合影） =====
# 1. 保守措辞（"repair... keep exactly the same"）对重度污损几乎无效——模型会把
#    "保持原样"执行得比"修复"更狠，污损原样保留。重度破损要用 "restore to how it
#    originally looked / reconstruct / rendered clearly and cleanly" 这类强措辞。
# 2. 代价：脸部是"合理重建"而非真实还原（原照片里脸已经糊了，这是物理极限）。
#    多换几个种子（KSampler 设 fixed 后改 seed）挑最像的一张。
# 3. resolution：**同时决定参考图被缩到多大**，不只是输出尺寸。
#    实际输出宽 = round(√(res²·宽高比)/32)·32；4:3 的横图 =>
#    res=480 → 544×416（快约 4.6 倍，但参考图也只剩 544 宽，脸看不清，模型容易自己发挥）；
#    res=1024 → 1152×864；res=1344 → 1536×1152；
#    **res=0 → 参考图保持原图尺寸**（1080×810 的图就是 1088×800），保轮廓最稳。
#    结论：想「脸型一模一样」就别用小分辨率，优先 res=0 或 1024 以上。
# 4. 轻度污损（只有折痕黄斑、脸还清楚）用保守变体即可，不会重画脸。
# 5. **看不见的信息要靠提示词写死，而且矫枉必须留余地**（三次迭代教训）：
#    - 人种：不写就把中国人修成非洲/土著面孔 → describe 写 "Chinese, East Asian eyes
#      with epicanthic fold"，avoid 排除 african / caucasian / native american features。
#    - 年龄是**双向**的：不写会修成 40 岁；但正向堆 "no wrinkles / delicate refined beautiful /

#      avoid 两头排除：middle aged / wrinkles / grey hair + child / teenager / underage。
#    - **脸型轮廓是修复的底线**：通用正向里已写死 "keep the head shapes, face outlines,
#      jawlines, cheekbones and facial proportions; do not slim, widen or reshape; do not make
